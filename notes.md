# 📅 12-Week Upgrade Roadmap

## **Phase 1 — Core Backend (Weeks 1–3)**

### Week 1 — Java Deep Dive

* Collections internals, concurrency
* CompletableFuture
* JVM, GC, memory model
* Java 8–17 features
* 30 LeetCode problems

### Week 2 — Spring Boot Mastery

* Bean lifecycle
* AOP (logging, auditing)
* Exception handling (ControllerAdvice)
* Profiles & config
* Micrometer + Actuator

### Week 3 — WebFlux + Reactive Patterns

* Mono, Flux, operators
* Backpressure
* WebClient with retry/timeouts
* R2DBC relationships
* Build: High-performance product service

## **Phase 2 — Microservices Architecture (Weeks 4–6)**

### Week 4 — Microservice Patterns

* API Gateway
* Load balancing
* Circuit breaker (Resilience4j)
* Retry, rate limiter
* Distributed logging (ELK)
* Swagger/OpenAPI

### Week 5 — Database Optimization

* PostgreSQL indexes
* EXPLAIN ANALYZE
* Partitioning
* JPA vs JDBC vs R2DBC
* Liquibase changelog strategy

### Week 6 — Event-Driven Architecture (Kafka)

* Topics, partitions, offsets
* Producers/consumers
* Schema Registry
* Outbox pattern
* Build: Order → Stock → Notification workflow
